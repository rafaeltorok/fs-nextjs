# Blogs List

Part of the final project from the <i>FullStackOpen: Next.js</i> course.

## Features

- Create and manage blogs
- Create your own reading list
- Like any blog you want

## Getting started

1. Register for a new account
2. Login to access your dashboard
3. Add your first blog
4. View, like or add any blogs to your personal reading list

<br />

Build using Next.js, React, Drizzle ORM and Tailwind CSS.<i>FullStackOpen: Next.js</i> course
